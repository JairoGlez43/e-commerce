# `.env.example`

> **Qué es:** la plantilla de las variables de entorno del proyecto · **Lo decidió:**
> [spec 0007](../../docs/specs/0007-whatsapp-order.md) · **Lo usan:** las personas que montan el
> proyecto (tú, Vercel en la feature 08) · **Usa:** nada

## Para qué sirve

El proyecto necesita un dato que no debe estar en el código: el número de WhatsApp que recibe
los pedidos. Ese dato va en un archivo `.env`, que git **ignora** (está en `.gitignore`), así que
nunca se sube a GitHub. Pero si `.env` no se sube, alguien que clone el repo no sabría qué poner.
Para eso está `.env.example`: **sí** se sube, con los mismos nombres pero valores falsos, y
explica el formato. Es la costumbre habitual en proyectos de Node.

## El código, por partes

```bash
# Copy this file to .env (gitignored) and put the real values there. Never commit .env.
```

- `#` empieza un comentario en este formato. Dice: "Copia este archivo a `.env` (que git ignora)
  y pon ahí los valores reales. Nunca subas `.env` al repo."

```bash
# WhatsApp number that receives orders (spec 0007): international format, digits only,
# no + or spaces. Example: Cuba is 53 + 8 digits. This one is fake.
WHATSAPP_NUMBER=5350000000
```

- El comentario: "Número de WhatsApp que recibe los pedidos (spec 0007): formato internacional,
  solo dígitos, sin `+` ni espacios. Ejemplo: Cuba es 53 + 8 dígitos. Este es falso."
- `WHATSAPP_NUMBER=5350000000`: el formato de cada línea es `NOMBRE=valor`, sin espacios
  alrededor del `=` y sin comillas. El nombre es el que lee `getWhatsAppNumber()` con
  `import.meta.env.WHATSAPP_NUMBER`. El valor es **falso** a propósito.

## Cómo se conecta

- **Tú:** copias este archivo como `.env` en la raíz del proyecto y cambias el número por el
  tuyo. `pnpm dev` y `pnpm build` cargan `.env` solos.
- **Vercel (feature 08):** la misma variable se pone en la configuración del proyecto en Vercel,
  porque allí no hay `.env`.
- **Claude:** nunca lee ni muestra `.env` (regla de `AGENTS.md`). Para sus pruebas usa un número
  falso en el propio comando: `WHATSAPP_NUMBER=5355555555 pnpm build`.
- **El código:** [`src/lib/whatsapp.ts`](src/lib/whatsapp.ts.md) lee la variable y
  [`src/env.d.ts`](src/env.d.ts.md) declara su tipo.

## Prueba tú

Crea tu `.env` (es el paso que pide la feature 07):

1. En el explorador de VS Code, clic derecho sobre `.env.example` → Copiar, y pégalo en la raíz.
   Renombra la copia a `.env`.
2. Cambia `5350000000` por tu número: código de país + número, solo dígitos (por ejemplo, un
   móvil de Puerto Rico sería `1787` + 7 dígitos).
3. Ejecuta `pnpm build`: termina bien. En la pestaña de Git de VS Code, `.env` **no** aparece
   como cambio, porque git lo ignora.
4. Para deshacer, basta con borrar `.env`; el próximo `pnpm build` fallará pidiendo el número.
