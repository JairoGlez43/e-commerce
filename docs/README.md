# docs/

Todo lo que el proyecto "sabe" vive aquí, en archivos, no en el chat.

| Carpeta / archivo | Qué contiene | Quién lo escribe |
|---|---|---|
| `brief.md` | Tu idea en tus palabras | Tú |
| `scope/` | Qué construir y en qué orden, con su estado | `/scope` (y avanzan sus casillas `/develop`, `/check`, `/test`, `/document`, `/sync`) |
| `specs/` | Cada decisión importante, como contrato | `/architect` (`/develop` solo mueve la línea de estado) |
| `reviews/` | Revisiones de código de "otro modelo" | `/check review` |
| `testing.md` | El framework de tests elegido | `/test` |
| `releases/`, `postmortems/` | Notas de versión e informes de incidentes | `/document` |
